# NTTrace_Forge
A Windows telemetry research project focused on Event Tracing for Windows (ETW) and native system interfaces.

# Overview

Explores the relationship between Windows processes, "ntdll.dll", and the ETW event-tracing infrastructure.

# Technical Areas

- Event Tracing for Windows (ETW)
- "ntdll.dll"
- "NtTraceEvent"
- Process enumeration
- Module inspection
- Native API resolution
- Virtual memory protection
- Remote process inspection

# Research Focus

- Understanding ETW architecture.
- Studying process-level telemetry.
- Examining the role of native Windows interfaces in event tracing.
- Investigating limitations of user-mode telemetry.

# Platform

- Windows
- C++
- Win32 API

# Disclaimer

For authorized telemetry and security-monitoring research.
